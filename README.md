## ✨ What I Do

📱 **Android Development** — Production-ready applications using Kotlin, Jetpack Compose, and modern Android APIs.

⚙️ **Android System Engineering** — System applications and platform-level features for a custom Android-based operating system.

🎨 **Design Systems** — Reusable UI components, consistent design patterns, and pixel-perfect interfaces.

🧪 **Quality Engineering** — Unit testing, screenshot testing, static analysis, and maintainable code.

🏗️ **Software Architecture** — Clean Architecture, SOLID principles, modularization, and separation of concerns.
